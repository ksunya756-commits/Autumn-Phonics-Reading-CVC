# Autumn Sound Garden

Браузерная игра для первых шагов в чтении английских CVC-слов. Ребёнок слушает три отдельные фонемы, самостоятельно соединяет их и читает слово; переход к следующему слову подтверждает учитель.

## Запуск

Для обычного использования можно открыть `index.html` двойным щелчком. В локальном режиме игра воспроизводит аудиофайлы напрямую и не требует сервера.

Для разработки или проверки размещения на сайте можно запустить локальный HTTP-сервер:

```powershell
cd "D:\My games AI\Autumn Phonics Reading CVC"
python -m http.server 8000
```

Затем откройте `http://localhost:8000/`. Подойдёт и любой другой статический HTTP-сервер, например `npx serve .`.

## Как проводить занятие

1. Выберите один из шести списков и порядок `In order` или `Mix`.
2. Нажмите `Start`. Игра проверит и декодирует все звуки, нужные выбранному списку.
3. Ребёнок нажимает на каждую букву. Световая отметка загорается только после полного окончания записи.
4. `Sound it out` воспроизводит три отдельные фонемы последовательно. Это помощь со звуками, а не запись слитного слова.
5. Кнопка `Read aloud` доступна сразу. Нажмите её, разрешите браузеру доступ к микрофону и произнесите слово целиком. Прослушивание букв и `Sound it out` можно использовать как подсказку.
6. При совпадении с текущим словом игра покажет светящуюся звезду и активирует `Next`. Если распозналось другое слово, можно спокойно повторить попытку.

Кнопка `Teacher` открывает проверку всех 17 букв (16 файлов: `c` и `k` используют общий звук `/k/`), громкость фонем и зазор между ними. Страница `preview.html` позволяет отдельно прослушать комплект. Техническое декодирование не заменяет человеческую проверку качества произношения.

## Управление и сохранение

- Клавиши `1`, `2`, `3` включают соответствующие позиции слова.
- `Enter` запускает доступный шаг `Read aloud` или выполняет `Next`.
- Прогресс, выбранный режим, перемешанная последовательность и текущая позиция сохраняются в `localStorage`.
- `Reset results` на главном экране после подтверждения обнуляет прогресс всех шести списков, не меняя остальные настройки.
- Кнопка звука в игре отключает только декоративные эффекты. Учебные фонемы остаются доступными.
- Интерфейс адаптирован для широких экранов, планшетов и телефонов; поддерживается полноэкранный режим.

## Проверка чтения через микрофон

Голосовая проверка использует встроенный в Chrome или Edge механизм распознавания английской речи (`en-GB`). Браузер может передавать звук своему онлайн-сервису распознавания, поэтому для проверки может потребоваться интернет. Игра не сохраняет запись и не добавляет её в прогресс: сохраняется только завершение слова после нажатия `Next`.
